# 00 · 서문 — 환경 설정과 재현 약속

> 목적: 이 책의 모든 코드가 독자의 머신에서도 같은 출력으로 도는지 확인한다.
> 소요: 10분.

## 0.1 버전 확인

이 책을 따라 하기 전에, 아래 한 줄로 환경을 먼저 확인해 볼게요.

```bash
python -c "import torch; print('torch', torch.__version__); print('cuda', torch.cuda.is_available())"
```

이 책이 쓰인 실제 출력은 이거예요:

```text
torch 2.8.0+cpu
cuda False
```

- `torch 2.8.0+cpu` — CPU 전용 빌드예요. GPU 빌드(`+cu121` 등)가 아니어도 상관없습니다. 이 책의 모든 예제는 CPU 기준으로 설계됐어요.
- `cuda False` — NVIDIA GPU가 없거나 연결돼 있지 않다는 뜻이죠. 근데 실망할 필요는 없어요. 이 책에서는 GPU를 요구하지 않습니다. GPU가 있어도 코드는 그대로 동작하고요.

> **참고**: 예제에 `torchvision`이나 `matplotlib`은 쓰지 않습니다. 실제로 이 머신에
> 설치돼 있지 않기 때문입니다(`find_spec`로 확인). 이미지 예제는 전부 합성 텐서로 만들었습니다.

## 0.2 재현성: 왜 숫자가 조금씩 다를 수 있나

같은 코드인데 마지막 자리 숫자가 달라 보일 수 있어요. 머신이나 PyTorch 마이너 버전에 따라 부동소수 연산과 난수 초기화가 미묘하게 다르게 돌아가기 때문이죠. 이 책이 취한 원칙은 이렇습니다.

1. 난수를 쓰는 예제는 전부 `torch.manual_seed(...)`로 고정했습니다. 같은 파이토치 버전이면 그대로 재현돼요.
2. 장에 실린 "실제 출력"은 위 2.8.0+cpu 환경에서 찍은 것입니다. `2.0045` vs `2.0047` 같은 미세 차이는 정상이에요.
3. 발산·수렴처럼 트렌드가 중요한 결론(03장)은 마지막 자리와 무관하게 성립합니다.

숫자 하나 안 맞아서 책 탓부터 하고 계신 거라면, 이번만 넘어가요. 두 번째 원칙이 바로 그 경우를 위한 조항입니다.
