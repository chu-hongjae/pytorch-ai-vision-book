# 00 · 서문 — 환경 설정과 재현 약속

> 목적: 이 책의 모든 코드가 독자의 머신에서도 같은 출력으로 도는지 확인한다.
> 소요: 10분.

## 0.1 버전 확인

이 책을 따라 하기 전에 아래 한 줄로 환경을 확인합니다.

```bash
python -c "import torch; print('torch', torch.__version__); print('cuda', torch.cuda.is_available())"
```

이 책이 쓰인 실제 출력:

```text
torch 2.8.0+cpu
cuda False
```

- `torch 2.8.0+cpu` — CPU 전용 빌드. GPU 빌드(`+cu121` 등)가 아니어도 상관없습니다. 이 책의 모든 예제는 CPU 기준으로 설계됐습니다.
- `cuda False` — NVIDIA GPU가 없거나 미연결. **이 책에서는 GPU를 요구하지 않습니다.** GPU가 있어도 코드는 그대로 동작합니다.

> **참고**: 예제에 `torchvision`이나 `matplotlib`은 쓰지 않습니다. 실제로 이 머신에
> 설치돼 있지 않기 때문입니다(`find_spec`로 확인). 이미지 예제는 전부 합성 텐서로 만들었습니다.

## 0.2 재현성: 왜 숫자가 조금씩 다를 수 있나

부동소수 연산과 난수 초기화 때문에, 같은 코드라도 머신·PyTorch 마이너버전에 따라 마지막 자리 숫자가 달라질 수 있습니다. 이 책이 취한 원칙:

1. **난수를 쓰는 예제는 전부 `torch.manual_seed(...)`로 고정**했습니다. 같은 파이토치 버전이면 재현됩니다.
2. 장에 실린 "실제 출력"은 위 2.8.0+cpu 환경에서 찍은 것입니다. 미세 차이(예: `2.0045` vs `2.0047`)는 정상입니다.
3. 발산·수렴처럼 **트렌드가 중요한 결론**(03장)은 마지막 자리와 무관하게 성립합니다.

## 0.3 학습 경로 제안

이 폴더의 원본 `README.md`에 적힌 학습 목표 3개가 이 책 3막에 대응합니다.

| 원본 학습 목표 | 이 책의 장 |

| 딥러닝 기본 개념 이해 | 01~03장 (tensor → autograd → loss/optimizer) |
| PyTorch tensor와 모델 구현 학습 | 04~05장 (`nn.Module`, 실제 학습 루프) |
| 이미지 분류 모델의 기본 구조 이해 | 06장 (CNN), 07장 (실습) |

처음부터 끝까지 순서대로 읽는 것을 권장하지만, 이미 tensor를 다룰 줄 안다면 01장을 건너뛰고
[02. Autograd](02_autograd.md)부터 시작해도 됩니다. 다만 **03장의 발산 실험은 건너뛰지 마세요** —
학습률이 왜 중요한지 몸으로 익히는 장입니다.

## 0.4 이 책이 다루지 않는 것 (범위)

로봇 비전 로드맵(`../README.md`)에서 이 단계 뒤로 가야 할 주제들은 의도적으로 제외했습니다.
- 전이 학습 / 사전학습 모델 (`torchvision.models`) — `torchvision` 미설치
- GAN, Transformer, 객체 탐지(YOLO 등) — 04_perception 이후 단계

이 책은 **"학습이라는 반복문 하나를 직접 손으로 이해한다"** 에 범위를 한정합니다.

## 정리

- PyTorch가 import되고 버전이 찍히면 준비 완료. GPU 불필요.
- 이 책 코드는 전부 CPU·`torch`/`numpy` 범위로, 실제로 실행한 결과만 실었다.
- 난수 예제는 시드 고정 — 재현 가능.
