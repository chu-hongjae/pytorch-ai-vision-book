# FE/BE 개발자를 위한 AI 전향 가이드

> **당신은 이미 개발자입니다.** 이 책은 변수·함수·API·배포를 설명하지 않습니다.
> 대신 **코드 짜는 방식의 직관이 AI에서 어디부터 꺾이는지**를, 실제로 실행한 숫자로 보여줍니다.

- **대상**: 프론트엔드/백엔드 실무 경험 1년 이상 + 딥러닝은 "그때그때 따라쳐본 수준" 이하인 사람
- **전제 아님**: 미분·확률론을 미리 알 필요는 없습니다. 필요한 순간에 3줄로 설명합니다.
- **검증 환경**: PyTorch 2.8.0+cpu, scikit-learn, numpy. GPU·`pandas`·`fastapi` 없이 전부 돌아갑니다.
- **신뢰 원칙**: 이 책의 모든 출력·수치는 이 머신에서 실행한 결과입니다. 예로 만든 숫자 하나 없음.

---

## 이 책의 주장 한 줄

> 일반 개발은 **"판단식을 작성하는 일"** 이고, AI는 **"판단식을 데이터에서 찾아오게 하는 일"** 이다.
> 그래서 AI의 코드 30줄 중 25줄은 모델이 아니라 **데이터·평가·서빙**이다.

이 전환을 이해하면 나머지(라이브러리 API, 논문, 용어)는 그냥 평범한 기술 스택입니다.
모르겠다고 느끼는 지점의 90%는 이 한 문장이 안 낀 상태입니다.
